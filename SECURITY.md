# Security Policy

## Scope

This repository contains synthetic data and proof-of-concept research software.
It is not approved for processing identifiable, confidential or operational
healthcare or criminal justice data.

## Reporting a concern

Do not include sensitive data, credentials or exploit details in a public issue.
Use GitHub's private vulnerability-reporting route if it is available for this
repository. For non-sensitive reproducibility defects, open a public issue with
the affected version, operating environment, command used and a minimal
synthetic example.

## Supported version

Security and reproducibility corrections are applied to the latest version on
the default branch. Version 1.0.0 is the archived reference release.
